# 지역자활센터 업무 도구

설치·로그인 없이 주소만 열면 바로 쓰는 자활센터 실무 도구 모음입니다. 사이트: https://jahwalktg.github.io/jahwal-tools/

- 적은 내용은 쓰는 사람의 PC·브라우저에만 저장되고, 인터넷으로 아무것도 보내지 않습니다.
- 참고용 도구이며, 지침·법령 판단은 담당 부서에서 확인하세요.
- 한 실무자의 개인적인 경험으로 만든 것이라 빈 곳이 있습니다. 쓰시는 분들의 적극적인 의견으로 함께 완성해 갑니다.
- 의견·문의는 사이트 첫 화면의 "의견·문의" 버튼(구글 설문·메일)으로.
- 만든 사람: 서울강남지역자활센터 김태균 (한국자활복지개발원 자활전문강사). 작업 방식 참고: 외부강사 김지백(모두의 AI교실).

이 저장소에는 빌드된 결과(HTML 파일)만 있습니다. 원본(src/)은 만든 사람의 PC에서 관리합니다.
