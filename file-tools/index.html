3이름·항목 읽기

「쪽에서 읽기」를 누르면 수료증처럼 쪽에 「성명 : ○○○」「사업단 : ○○」처럼 적힌 항목을 모두 읽어, 이름을 채우고 항목(사업단·생년월일·교육과정…)을 파일 이름과 「골라서 받기」에 쓸 수 있게 합니다. 스캔본(글자 없는 그림)은 못 읽으니 그때는 이름 목록을 한 줄에 한 명씩 붙여 넣으세요. 미리보기 아래 칸은 직접 고칠 수 있습니다.
